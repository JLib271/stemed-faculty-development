# STEMEd+ Faculty Development has moved

This list is now part of **STEMEd+ Professional Development**:
**https://jlib271.github.io/stemed-professional-development/** ([repository](https://github.com/JLib271/stemed-professional-development)).

The new site combines STEMEd+ Professional Learning (K-12 and informal educators) and STEMEd+ Faculty
Development (college faculty, instructors, graduate students, and postdocs), with a filter for your role.

The old address, https://jlib271.github.io/stemed-faculty-development/, still works: it sends visitors to the new site, keeping any filters in their link.
Its calendar (`feeds/deadlines.ics`) and RSS (`feeds/new.xml`) are copies of the combined site's, refreshed
daily, so existing subscriptions keep working.

To suggest or correct a program, use the
[new repository](https://github.com/JLib271/stemed-professional-development/issues/new/choose).
The history of this list stays here.
